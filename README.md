# OptiCoC - 镜头光学与离焦弥散圆 2D/3D 可视化分析工具

基于高斯薄透镜几何光学模型的单文件 Web 应用，用于定量计算与对比两支摄影镜头在**不同拍摄距离（$u_0$）**与**不同背景距离（$d$）**下的**离焦弥散圆半径（Circle of Confusion Radius, $r$）**。

## ✨ 核心特性

- **2D / 3D 双模式交互视图**：
  - **2D 曲线（Retina 高清渲染）**：直观展示等构图（相同像方放大率 $M$）下弥散圆半径随背景距离的变化曲线，并自动标出**虚化反超临界点 $d^*$**。
  - **3D 曲面（基于 Plotly.js）**：支持在三维空间中自由旋转对比两支镜头的弥散圆曲面，一键切换「同机位物距对比」与「等构图退后对比（含绿色空间反超交线）」。
- **桌面端 / 移动端智能识别**：
  - 自动结合浏览器 `User-Agent` 与视口宽度（`matchMedia`）切换桌面双栏与手机单列布局，同时保留顶部手动切换与一键恢复自动按钮。
- **Excel 兼容 CSV 导出**：
  - 支持一键导出单支镜头的二维交叉矩阵表（`*_matrix.csv`）及双镜头汇总结构化明细表（`*_detailed.csv`），内置 UTF-8 BOM 头，Excel 直接双击打开无乱码。

## 📐 光学数学模型

设镜头焦距为 $f$，光圈值为 $F$，合焦主体物距为 $u_0$，背景距主体距离为 $d$（背景物距 $u = u_0 + d$），传感器焦平面上的离焦弥散圆半径 $r$ 为：

$$r = \frac{c}{2} = \frac{f^2}{2 \cdot F} \cdot \frac{\vert{}d\vert{}}{(u_0 + d)(u_0 - f)}$$

在**等构图（像方放大率 $M = \frac{f}{u_0 - f}$ 恒定）**条件下，两支镜头（$f_1, F_1$ 与 $f_2, F_2$）虚化光斑大小相等的**临界背景距离 $d^*$** 为：

$$d^* = \left(1 + \frac{1}{M}\right) \cdot \frac{f_1 f_2 (F_2 - F_1)}{f_2 F_1 - f_1 F_2}$$
